# WCMusic Desktop Design Direction

Native Windows music player built in Rust GPUI. Match the existing exclusive now-playing screen and persistent player bar: compact controls, generous song/lyrics area, semantic light/dark palette, green playback accent, Chinese UI text, restrained borders and surfaces. Keep the album artwork and synchronized lyrics as the focus. Provide a small familiar effects entry in the song-detail/player controls and a concise anchored panel with a clear title, one spatial-audio switch, concise status, and a route back to playback settings if needed. The setting must reflect the existing global persisted state. Do not invent EQ bands or other audio processing that the engine does not support. This is a native desktop UI reference, not a web landing page; avoid browser chrome, marketing copy, decorative imagery, or changes to the existing page composition.
