# MiSans 字体资源

MiSans 由小米提供。现有 Regular、Medium、Semibold、Bold 文件继续用于项目。

新增 `MiSans-Thin.ttf` 为未修改的字体文件，来源：
https://github.com/boyan01/mi_sans_font/blob/main/lib/fonts/MiSans-Thin.ttf

MiSans 官方说明及使用条款：
https://hyperos.mi.com/font/

桌面客户端按 CSS 字重加载对应文件：Thin 100、Regular 400、Medium 500、Semibold 600、Bold 700。
